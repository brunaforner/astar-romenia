# astar-romenia
Busca A* de Arad a Bucareste (Russell & Norvig, cap. 3),
feita em 6 fases na disciplina IIA-008 Inteligência Artificial I.
Aluna: Bruna Tamis Forner



## Como rodar
 python a_estrela.py
## Resultado
Arad -> Sibiu -> Rimnicu Vilcea -> Pitesti -> Bucharest
(418 km em 4 passos, igual à Figura 3.24 do livro)
## Fases
| Arquivo | Conteúdo |
|---|---|
| fase1_explorar.py | navegar nos dados |
| fase2_caminhos.py | percorrer o caminho e questionar o custo |
| fase3_fronteira.py | Monta o nó de busca e a fronteira |
| fase4_expandir.py | Aplica funções, adiciona explorados |
| fase5_busca.py | Juntar em uma função, código completo |
| a_estrela.py | O programa completo e apresentável|
